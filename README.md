# Adventure Game (Python Text-Based Game)

## Overview
This project is a Python-based text adventure game developed as part of university coursework. The game allows players to navigate through different rooms, interact with items, and manage an inventory using text commands.

The project was built incrementally through structured lab exercises focused on game development, command parsing, and software testing.

---

## Features
- Room-to-room navigation
- Text-based command parser
- Inventory management system
- Item pickup and drop mechanics
- Input normalisation and validation
- Interactive menu system
- Doctest-based testing
- Git and GitHub version control

---

## Technologies Used
- Python
- Git
- GitHub
- Command Line Interface (CLI)
